# 09. 블록과 아이템

CaG가 새로 넣는 블록은 다섯이다(금고 외벽은 금고의 일부라 따로 세지 않는다). 나머지 설비(작업대, 화로, 모루, 침대, 집 안 상자)는 바닐라 것을 그대로 쓴다.

| id | 이름 | 한 줄 설명 | 단계 |
|---|---|---|---|
| `plaza_block` | 광장 블록 | 도시의 시작점. 도시 패널을 연다 | 1 |
| `mint` | 주조대 | 구리 주괴를 녹여 화폐를 발행한다 | 1 |
| `map_table` | 지도 테이블 | 도시를 색으로 그린 평면 지도. 도시 패널을 연다 | 1 |
| `locker` | 사물함 | 작업구역의 작업함·판매함·주문 창구 | 2 |
| `vault_block` | 금고 블록 | 철 블록 26개로 감싸면 도시 금고가 된다 | 4 |
| `vault_casing` | 금고 외벽 | 금고가 된 뒤의 철 블록 자리. 아이템은 없다 | 4 |

아이템: `coin`, `coin_10`, `coin_100`(1단계), `job_book`(5단계). `01-architecture.md` 2절.

제작법은 전부 임시다. 재료는 닫힌 경제 안에서 구할 수 있는 것으로만 잡는다.

## 1. 광장 블록 `plaza_block`

- 놓으면 도시 세우기 화면이 뜬다. 다른 도시의 관리 청크 안에는 못 놓는다.
- 우클릭: 도시 패널. 세금 납부 지점(5블록 안).
- **잠금(D-55):** 도시가 있는 광장 블록은 시장도 부술 수 없다. 도시 패널에서 "도시 해체 허용"을 켜고 주민이 0명일 때만 시장이 부술 수 있고, 부수면 도시가 없어진다. 허용은 저장되지 않아 서버가 다시 뜨면 꺼진다.
- **옮기기(D-55):** 시장이 자기 도시의 관리 청크 안에 새 광장 블록을 놓고 우클릭하면 확인 화면이 뜬다. 승인하면 새 블록이 도시의 광장 블록이 되고, 옛 블록은 아이템으로 떨어진다. 시장이 아닌 사람은 관리 청크 안에 광장 블록을 놓을 수 없다.
- 금고가 없을 때는 폭동의 목표가 된다.
- 제작법(임시): 돌 벽돌 4 + 종 1 + 금 주괴 4.

## 1-2. 주조대 `mint` (D-56)

화폐 발행에는 재료가 든다. 시장이 구리를 구해 와서 직접 찍어야 돈이 생긴다.

- 구리 주괴를 들고 우클릭하면 든 묶음이 들어간다(상한 27묶음). 빈손 우클릭은 주조 화면.
- 주조 화면에서 녹일 주괴 수를 넣고 "주조"를 누르면, 그만큼 구리가 사라지고 `주괴 수 × §mint.coins_per_ingot` 이 금고 잔고와 발행 누계에 더해진다. 권한 `ISSUE`.
- 넣어 둔 구리는 도로 꺼낼 수 있다. 블록이 부서지면 구리가 떨어진다.
- 그 주조대가 놓인 관리 청크의 도시에 발행된다. 관리 청크 밖에서는 동작하지 않는다.
- 주조된 돈은 숫자로 금고 잔고에 들어간다. 동화 아이템은 금고 블록에서 인출할 때만 생긴다(D-53).
- 1.21.1에는 구리 조각이 없어서 주괴를 단위로 잡았다. 주괴 1개 = 9는 구리 주괴의 임시 기준가와 같은 값이다.
- **뒤로 미룬 것:** 주조에 드는 시간과 가공 단계, 호퍼·Create로 구리 넣기, 자동 발행(D-51)이 주조대의 구리를 쓰게 하기.
- 제작법(임시): 철 주괴 3(윗줄) + 구리 블록 1(가운데) + 매끄러운 돌 3(아랫줄).

## 2. 사물함 `locker`

작업구역에서 일하는 주민 한 명의 것이다. 그 주민이 만든 물건과 작업 도구를 넣어 두고, 손님은 여기서 사고 주문한다.

### 기본
- 블록 하나, 방향이 있다. 블록 엔티티가 `§locker.slots` 칸의 인벤토리를 가진다. 상자처럼 여닫는 모습.
- 블록 엔티티가 주인(가구 id, 주민 id)을 저장한다. 주인이 있으면 앞면 명패에 주민 이름과 직업 표식이 보인다.
- 폭발에 부서지지 않는다.
- **호퍼 같은 자동화가 붙지 않는다(D-49).** 아이템 처리 능력을 밖으로 내놓지 않는다. 소유와 절취 판정을 지키기 위해서다.

### 주인과 정원
- 주민이 작업구역에 배정되면 그 구역 안의 주인 없는 사물함 하나를 잡는다(`ContainerClaim` 의 `WORK`). 직업을 내려놓으면 푼다.
- **작업함은 사물함만 된다.** 바닐라 상자는 작업함이 되지 않는다.
- **작업구역의 정원 = min(직업의 정원 식, 그 구역의 사물함 수).** 사물함이 곧 자리다.
- 구역마다 역할이 정해지는 사물함:

| 놓인 곳 | 역할 | 주인 |
|---|---|---|
| 작업구역 | `WORK`: 작업함 + 판매함 + 주문 창구 | 배정된 주민의 가구 |
| 광산 구역, 입구에서 가장 가까운 것 | `MINE_COOP`: 조합 사물함 | 광산 조합 |
| 광장 구역 | `CITY_SALE`: 시 판매함 | 시 |
| 그 밖(구역 밖, 거주구역) | 역할 없음. 보통 상자처럼 쓴다 | 그 자리의 규칙대로 |

### 든 물건의 구분
칸을 나누지 않고 품목으로 판정한다(`03-economy.md` 4절).

| 구분 | 무엇 | 매물인가 |
|---|---|---|
| 도구 | 그 직업의 도구. 쓰는 것과 예비품 | 아니다 |
| 재료 | 그 직업 레시피의 재료 | 아니다 |
| 주문품 | 주문받아 만든 것. 주문자 몫 | 아니다 |
| 산출물 | 그 직업의 `sells` 품목 | 매물이다 |

- 주민은 일을 시작할 때 사물함에서 도구를 꺼내 들고, 끝나면 넣는다. 예비품은 사물함에 둔다.

### 상호작용
| 누가 | 무엇을 |
|---|---|
| 주인 주민 | 넣고 꺼낸다 |
| 다른 주민 | 3블록 안에서 사고, 주문하고, 주문품을 받아 간다. 주인이 없어도 된다 |
| 플레이어 (우클릭) | 사물함 화면: **매물** 탭(금고 돈으로 구매), **주문** 탭(금고 돈으로 발주, 완성되면 여기서 받는다), **내용물** 탭(보기) |
| 플레이어가 내용물을 꺼냄 | 된다. 다만 시정부면 절취로 판정한다(`06-governance.md` 7절). 꺼내기 단추에 경고를 띄운다 |
| 플레이어가 넣음 | 선물이다 |
| 플레이어가 부숨 | 주인 없는 것은 누구나. 주인 있는 것은 `EDIT_ZONES` 권한자만 되고, 절취로 판정한다. 내용물은 떨어진다 |

- 시 판매함(`CITY_SALE`)은 권한자가 열면 보통 상자 화면 + 품목별 값 설정이 나온다.

### 제작법 (임시)
판자 6 + 철 주괴 2 + 상자 1 → 사물함 1. 목수의 주문 품목이다.

## 3. 지도 테이블 `map_table`

도시의 관리 청크를 위에서 내려다본 모습을 **색으로만** 그린 평면 지도다. 블록 모양을 본뜨지 않는다. 지형, 구역, 직종이 한눈에 구분되는 것이 목적이다.

### 그리는 것
해상도는 블록 한 칸 = 한 화소. 두 층을 겹친다.

**지형 층** — 갱신할 때 찍어 둔다.
- 칸마다 맨 위 블록(지표 높이맵)의 바닐라 지도 색 분류(`MapColor`)를 읽어, 테이블 재질에 어울리는 양피지 톤의 팔레트 10색으로 줄인다.

| 분류 | 예 |
|---|---|
| 물 | 물, 얼음 |
| 풀 | 잔디, 이끼 |
| 흙 | 흙, 경작지, 진흙 |
| 모래 | 모래, 자갈 |
| 돌 | 돌, 심층암, 광석 |
| 나무 | 잎, 원목 |
| 눈 | 눈 |
| 건물 | 판자, 벽돌, 유리, 양털 등 사람이 놓는 블록 |
| 용암 | 용암, 불 |
| 기타 | 위에 안 드는 것 |

- 높이 음영: 북쪽 칸보다 높으면 한 단계 밝게, 낮으면 한 단계 어둡게(바닐라 지도와 같은 방식).

**구역 층** — 구역이 바뀔 때마다 자동으로 바뀐다.
- 구역에 든 칸은 구역 색을 60% 섞고, 구역의 테두리 한 화소는 진하게 그린다.
- 거주구역은 한 색. 광장, 감옥, 초소는 각각 한 색.
- **작업구역은 직종마다 색이 다르다.** 색은 직업 JSON의 `map_color` 에서 읽는다.
- DaB가 있으면 길 태그를 길 색으로 그린다.

**그 밖**
- 관리 청크가 아닌 곳은 그리지 않는다(테이블 바탕이 보인다). 청크 경계는 옅은 선.
- 광장 블록과 금고의 위치에 작은 표식.

### 갱신
- **지형 층은 수동으로만 갱신한다.** 지도 화면의 "지도 갱신" 단추. 권한 `EDIT_ZONES`. 쿨다운 `§map.refresh_cooldown_ticks`.
- 서버가 관리 청크 전부의 높이맵을 읽어 다시 만든다. 청크 49개라도 12,544칸이라 한 틱에 끝난다.
- 도시를 세울 때와 관리 청크를 더할 때는 그 청크만 자동으로 한 번 찍는다.
- 갱신하면 `CityMap.version` 이 오르고, 테이블을 보고 있는 클라이언트에 새 자료를 보낸다(한 칸 1바이트, 압축).

### 크기
- 테이블 하나는 윗면에 지도 전체를 맞춰 그린다.
- **같은 높이로 붙여 놓은 테이블은 하나의 판으로 합쳐진다.** 직사각형이어야 하고 최대 `§map.max_tables` × `§map.max_tables`. 지도는 판 전체에 맞춰 커진다. 3×3을 권한다.

### 상호작용
- 우클릭: 도시 패널(광장 블록과 같다).
- Shift + 우클릭: 지도 화면. 크게 보기, 범례, 구역에 마우스를 올리면 이름·직종·배정 인원, 갱신 단추, 칸을 누르면 그 자리로 Lib 편집창 열기.
- 관리 청크 안에만 놓을 수 있다. 도시에 여러 개 놓아도 된다.

### 자료와 렌더
```
CityMap { minX, minZ, width, height, terrain: byte[width × height], version, refreshedDay }
```
- 도시 저장 데이터에 둔다. 구역 층은 저장하지 않고 `ZoneIndex` 에서 만든다.
- 클라이언트는 도시마다 동적 텍스처 한 장을 만들어 캐시하고, 각 테이블의 블록 엔티티 렌더러가 윗면 바로 위에 자기 몫의 조각을 그린다.
- 입체로 올리지 않는다. 나중에 원하면 높이를 몇 단계로 나눠 살짝 돋우는 정도만 더할 수 있다.

### 뒤 단계에서 더할 수 있는 표식
사건이 난 자리(6단계), 정보 부관의 감시 대상 가구(9단계), 집단 행동이 모인 곳(7단계). 전부 공개 자료만 쓴다.

### 제작법 (임시)
판자 4 + 종이 4 + 나침반 1.

## 4. 금고 `vault_block`

### 조립 (D-54)
- **금고 블록 하나를 가운데 두고, 둘레 26칸을 바닐라 철 블록으로 빈틈없이 채우면** 3×3×3 금고로 변한다. Create의 아이템 금고처럼 여러 블록이 하나의 구조물이 되는 방식이다.
- 변하는 순간 철 블록 26개는 `vault_casing`(금고 외벽)으로 바뀐다. 금고 외벽은 **이어진 텍스처**를 써서 3×3×3 전체가 한 덩어리로 보이고, 앞면 3×3에는 둥근 회전식 문이 그려진다.
  - 금고 외벽의 블록 상태: 덩어리 안의 자리(x, y, z 각각 0~2)와 앞면 방향. 모델은 자리에 맞는 텍스처 조각을 쓴다.
  - 금고 외벽은 아이템이 없다. 풀리면 철 블록으로 돌아간다.
- **판정 시점:** 금고 블록이나 철 블록이 놓일 때, 그 칸에서 한 칸 안에 있는 금고 블록마다 둘레 26칸을 검사한다.
- **앞면:** 마지막 블록을 놓은 플레이어를 향한 수평 면.
- 가운데 금고 블록의 블록 엔티티가 금고의 자료(창고, 앞면)를 가진다.
- 관리 청크 안에서만 변한다. 여러 개 만들 수 있고 창고는 금고마다 따로다. 금고 잔고(돈)는 도시에 하나라서 어느 금고에서 보아도 같다.
- **풀기:** 창고가 비어 있을 때 시장만 외벽을 부술 수 있다. 하나를 부수면 금고가 풀려 나머지 외벽이 철 블록으로 돌아가고, 부순 자리에서는 철 블록이 나온다. 폭발과 주민에게는 부서지지 않는다.
- 변하기 전의 금고 블록은 보통 블록이다. 누구나 놓고 부술 수 있다.

### 기능
| 기능 | 내용 | 명세 |
|---|---|---|
| 인출과 입금 | 금고 잔고 ↔ 동화 아이템 | `03-economy.md` 1절 |
| 시 창고 | `§vault.slots` 칸. 수매품, 압류·몰수품, 플레이어가 넣은 물건 | |
| 수매 창구 | 주민이 잉여를 가져와 하한가에 판다 | `03-economy.md` 8절 |
| 시 판매와 방출 | 창고의 품목을 값을 정해 주민에게 판다 | `03-economy.md` 8절 |
| 부관의 출납 | 규칙의 `buy`, `give` 를 수행할 때 여기서 넣고 꺼낸다 | `06-governance.md` 5절 |

- **금고가 없으면** 인출, 입금, 수매, 방출을 못 한다. 세금, 봉급, 발행, 금고 돈으로 사는 것은 금고 없이도 된다(잔고는 도시 자료의 숫자다). 압류품은 광장 구역의 사물함으로 간다.
- 창고가 차면 수매가 멈추고 도시 패널에 경고가 뜬다.

### 접근
- 열 수 있는 사람: 시장, `TREASURY_SPEND` 권한이 있는 의원, 규칙을 수행 중인 행정 부관.
- 열면 문이 30틱 동안 돌며 열리는 모습이 나오고 화면이 뜬다.
- 주민은 문을 열지 않는다. 앞면 3블록 안에서 수매와 구매를 한다.
- 금고의 물건을 시정부가 꺼내는 것은 범죄가 아니다.

### 화면
| 탭 | 내용 |
|---|---|
| 잔고 | 잔고, 인출, 입금, 최근 출납 기록 |
| 창고 | 쪽 넘김, 검색, 분류별 자동 정렬 |
| 수매 | 켬/끔, 품목별 수매 여부, 하루 예산, 자금이 모자랄 때 자동 발행(기본 꺼짐) |
| 판매 | 품목별 판매 여부와 값, 식량 자동 방출(기본 켜짐) |

- **내부 정리는 자체 구현한다(D-52).** 품목을 분류(식량, 원자재, 광물, 도구, 살림, 기타)로 나눠 자동 정렬하고, 같은 품목은 한데 모은다. 구리 골렘은 1.21.1에 없어서 그 코드는 쓸 수 없다.

### 폭동과 금고 (D-50)
- 금고가 있으면 폭동의 첫 목표는 주 금고(가장 먼저 변한 것)다.
- 무리가 앞면에 닿아 `§riot.vault_break_ticks` 동안 문을 두드리면 열린다. 그 시간이 경비병이 막을 시간이다.
- 열리면 금고 잔고의 `§riot.loot_share` 를 나눠 갖고, 참가자마다 창고에서 2묶음까지 들고 간다.
- 조직의 금고 털이는 뒤로 미룬다.

### 제작법 (임시)
철 주괴 8개를 조합대 가운데만 비우고 둘러 놓으면 금고 블록 1개. 금고 하나에는 금고 블록 1개와 철 블록 26개, 곧 철 주괴 242개가 든다. 도시가 자리 잡은 뒤에 짓는 시설이다. 그 전에는 시 수매, 방출, 동화 인출이 없다(사용자 결정: 처음부터 시장이 돌지 않아도 된다).

## 5. 검토하고 넣지 않은 블록

| 후보 | 판단 | 이유 |
|---|---|---|
| 갱도 표지(거리마다 놓아 귀환 범위를 재는 블록) | 넣지 않는다 (D-48) | 광산은 `MinePlan` 이 통로 그래프를 이미 갖고 있어서, 입구까지의 거리는 블록 없이 계산된다. 블록에 기대면 플레이어나 폭발이 블록을 없앴을 때 계산이 깨진다. 주민이 놓을 블록을 대 줄 공급망도 하나 더 필요해진다. 귀환 계산식은 `04-jobs.md` 8절 |
| 광산 거점 수납함 | 넣지 않는다 | 지하 숙박을 뺐다(D-30). 캔 것은 광부가 들고 나와 입구의 조합 사물함에 넣는다 |
| 판매대 | 넣지 않는다 | 사물함이 판매함을 겸한다 |
| 주문대 | 넣지 않는다 | 사물함이 주문 창구를 겸한다 |
| 납세함 | 넣지 않는다 | 광장 블록이 납부 지점이다 |
| 게시판 | 넣지 않는다 | 요청은 요청함으로, 벽보는 바닐라 표지판으로 된다 |
| 초소·감옥 전용 블록 | 넣지 않는다 | 구역과 바닐라 침대·문으로 된다 |
| 여물통 | 넣지 않는다 | 목장주가 직접 먹인다 |

새 블록을 더하는 기준: **구역과 바닐라 블록과 자료만으로는 안 되는 일이 있을 때만.** 사물함은 소유와 자리를, 금고는 큰 창고와 약탈 지점을, 지도 테이블은 한눈에 보는 화면을 주기 때문에 넣었다.
