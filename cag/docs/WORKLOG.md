사용자 제안과 시뮬레이터 2판 결과로 아래를 정했다. **이 목록이 명세에 다 들어갔는지는 맨 아래 "반영 상태"를 본다.**

경제
- D-37 호가 = 기준가 × P × 배수. 배수는 0.5~2.0.
- D-38 기준가는 손으로 정하지 않고 노동 시간으로 계산한다(1차 품목 = 기준 일당 ÷ 하루 산출, 가공품 = 재료 + 작업 시간 몫 + 도구 감가).
- D-39 물가 기준선 P는 가구 지갑의 평균이 아니라 **중앙값**으로 잡는다. 평균이면 수매+발행에서 물가가 6.9배가 됐다.
- D-40 내구재(도구, 가구, 침대, 책, 갑옷)는 **주문 생산**. 선금 50%. 소모품(음식, 숯, 횃불)은 소량 재고.
- D-41 작업자는 필수 도구의 **예비품 1개**를 사물함에 둔다.
- D-42 여윳돈 소비는 욕구가 찼는지와 무관하다. 굶는 가구 12.3 → 2.2로 가장 큰 효과.
- D-43 **시 수매**: 금고가 하한가로 잉여를 산다. 조건 셋: 잉여분만(목표 재고 초과분), 가구별 한도 = 생계비 − 그날 소득, 산 식량은 다시 판다(방출).
- D-44 **아사 도입**: 허기 0이 5일 이어지면 사망. 영입 뒤 유예 기간. D-12를 대체.
- D-51 수매 자금이 모자랄 때의 자동 발행은 정책 스위치(기본 꺼짐).

블록 (사용자 지시)
- D-45 **사물함**: 작업구역의 작업함·판매함·주문 창구. 작업함은 사물함만 된다. 정원 ≤ 사물함 수.
- D-46 **지도 테이블**: 지형과 구역을 색으로만 그린 평면 지도. 수동 갱신. 붙여 놓으면 커진다. 우클릭하면 도시 패널.
- D-47 **금고**: 금고 블록 3×3×3 다중 블록. 앞면이 회전식 문. 동화 인출·입금, 수매, 방출은 금고에서.
- D-48 갱도 표지 블록은 만들지 않는다. 귀환 시각은 광산 계획의 통로 그래프 거리로 계산한다.
- D-49 사물함과 금고에는 호퍼 같은 자동화가 붙지 않는다.
- D-50 폭동의 약탈 대상은 금고(없으면 광장 블록).
- D-52 구리 골렘 코드는 쓰지 않는다(1.21.1에 없다). 금고 내부 정리는 자체 구현.
- D-54 금고 블록 = 철 주괴 8개(고리). 금고 블록 1개를 철 블록 26개로 감싸면 금고로 변하고 이어진 텍스처가 씌워진다(2026-11-17 사용자 지시).
- D-53 영입과 돈 건네기는 동화 아이템 없이 화면에서 금고 잔고로 한다(금고 블록을 짓기 전에는 아이템을 꺼낼 수 없어서).

## 개발 진행

소스: 이 폴더의 `src/` (단독 빌드), GitHub `dAM0419/minedraft` 의 `cag/` (Lib·DaB 와 한 저장소).
빌드: Lib 폴더의 `build.bat` → 이 폴더의 `build.bat`. CaG 0.1.0 은 **Lib 0.1.11 이상**이 필요하다.

### 1단계 (도시)

| 조각 | 내용 | 상태 |
|---|---|---|
| 1a (0.1.0) | 모듈 뼈대, 수치 로더(`Params`, 명세 08에서 뽑은 `cag_params.properties`), 광장 블록, 도시 세우기 화면, 도시 저장(`City`, `CityManager`), 권한, 시 레벨 표, 구역 태그 21개와 도시 영역 종류, Lib 편집창 연결, 발행, 청크 일괄 로딩, 도시 시계와 결산 뼈대, 도시 패널(개요·구역 편집·발행·강제 로딩) | 작성, 컴파일 확인. **게임 안 시험 전** |
| 1b | `ZoneIndex`·`ZoneData`(구역 이름, 면적, 구역 안 판정), 편집창의 구역 정보, 의회 편집 화면 | 아직 |
| 1c | 지도 테이블(지형 층·구역 층, 붙여서 키우기, 지도 화면) | 아직 |
| 1d | 인수 기준 15개를 게임 테스트로, 텍스처 정리 | 아직 |

Lib 0.1.11: `AreaRules` 추가(영역 종류별 청크 상한과 청크 변경 거부). 도시의 청크 상한을 시 레벨로 묶는 데 쓴다.

1a 에서 정한 것
- 청크 로딩은 바닐라 강제 로딩(`setChunkForced`)으로 했다. 서버가 뜰 때 지난 실행의 강제 로딩을 모두 풀고 꺼진 상태로 시작한다. NeoForge 의 청크 표 제어로 바꿀지는 시험 뒤에 정한다.
- 도시를 없애도 Lib 영역 자료 파일은 남는다(Lib 에 영역 삭제가 없다).
- 시 레벨 표는 아직 코드에 있다(`CityLevel`). 데이터 파일로 옮기는 것은 뒤로.
- 텍스처는 임시 그림이다.

1a 를 게임에서 볼 것 (07-stages.md 1단계 인수 기준 중 1~4, 7~9, 11~13)
1. 광장 블록을 놓고 누르면 도시 세우기 화면이 뜨고, 세우면 도시 패널이 뜬다. 재접속 뒤에도 남는다.
2. 패널의 "구역 편집"으로 Lib 편집창이 열리고, 구역 태그 21개가 보이고 칠해진다(개체 번호).
3. 청크는 9개까지만 늘어난다.
4. 발행하면 금고 잔고와 발행 누계가 같이 오른다.
5. 멀리 가면 10초 뒤 "꺼져 있습니다", 돌아오면 켜진다. 강제 로딩을 켜면 멀리 가도 켜져 있다.
6. 도시 날짜는 켜져 있을 때만 오른다.
7. 다른 도시의 관리 청크에는 광장 블록이 놓이지 않는다. 광장 블록은 시장만 부술 수 있고 부수면 도시가 없어진다.
